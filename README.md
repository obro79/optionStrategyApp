# Option Strategy App

A powerful, interactive application built with [Streamlit](https://streamlit.io/) that allows users to simulate and analyze various options strategies. Designed with quantitative finance in mind, this tool helps you visualize profit/loss profiles, assess risk metrics, and explore different market scenarios—all through an intuitive web interface.

## Features

- **Strategy Simulation:**  
  Model a range of options strategies by adjusting key parameters such as strike prices, expiry dates, underlying asset prices, and implied volatility.

- **Interactive Visualizations:**  
  Generate dynamic profit/loss diagrams and risk graphs to better understand potential outcomes.

- **Real-Time Analysis:**  
  Input live market data or simulated data to see the real-time impact on your chosen strategies.

- **User-Friendly Interface:**  
  Leverage the simplicity and power of Streamlit for a seamless and interactive experience.

## Tech Stack

- **Python 3.x**
- **Streamlit**
- **Pandas**
- **NumPy**
- **Matplotlib/Plotly** (for visualizations)
